# 家庭管理技能注册表

> 新skill加入时，在此文件末尾按相同格式追加条目。

## self-driven-parenting（自驱型育儿顾问）

**来源**：基于《自驱型成长》（The Self-Driven Child）科学育儿方法论

**核心领域**：
- 孩子自律/自驱力/内驱力培养
- 父母角色定位与亲子沟通方式
- 孩子学习动力、作业问题、学业压力
- 孩子焦虑、压力、情绪管理
- 电子产品使用管理与屏幕时间
- 表扬方式、激励机制与成长型心态
- 睡眠、停工期与大脑健康
- 家庭教育原则、规矩制定与边界设定
- 顾问型父母、非焦虑临在等育儿理念实践

**触发关键词/场景**：
- "孩子不主动学习""作业拖拉""写作业磨蹭"
- "怎么让孩子自觉""孩子不自觉"
- "电子产品管理""屏幕时间""玩手机"
- "怎么表扬孩子""奖励机制"
- "孩子焦虑""孩子压力大"
- "家庭规矩""怎么定规则"
- "顾问型父母""非焦虑临在"
- "睡眠不好""休息时间不够"

**典型用户问题示例**：
- "孩子写作业总是磨蹭到很晚怎么办？"
- "怎么让孩子主动学习不用我催？"
- "孩子一玩游戏就停不下来，怎么管？"
- "我该用物质奖励来激励孩子学习吗？"
- "孩子考试前总是很焦虑，我该怎么帮他？"
- "我想当顾问型父母，具体怎么做？"

**与相邻skill的边界区分**：
- vs child-dev-learning：如果孩子"磨蹭"伴随明显的发育异常信号（如坐不住、漏题、写字极慢），优先走child-dev-learning排查发育/能力问题；如果只是态度/习惯问题，走self-driven-parenting
- vs structured-thinking-decision：self-driven-parenting聚焦"怎么做"（执行层面），structured-thinking-decision聚焦"选什么"（决策层面）。当用户问"要不要/选哪个"时，后者优先
- vs brain-health-advisor：self-driven-parenting从心理动机角度解释问题，brain-health-advisor从大脑发育/认知机制角度解释。两者可互补
- vs li-xigui-parenting-guide：self-driven-parenting侧重心理动机和内驱力机制，li-xigui-parenting-guide侧重方法论体系和工具使用。当用户提到李希贵或具体工具（三明治法则/三句话公式等）时，li-xigui优先；当用户讨论焦虑、内在动机时，self-driven优先。两者可互补

## li-xigui-parenting-guide（李希贵家庭教育指南）

**来源**：基于李希贵校长《家庭教育指南》完整方法论体系

**核心领域**：
- 家庭教育10条原则
- 7个家长角色定位
- 7个关键动作
- 工具箱：三明治法则、三句话公式、六词家教、10/10/10决策
- 24种方法、10项任务、10个工具
- 各年龄段（婴儿期到成年期）教育策略
- 随时表扬、定期反思、搭建阶梯、供给资源等具体方法
- 教育学首先是关系学

**触发关键词/场景**：
- "李希贵""家庭教育指南""教育学首先是关系学"
- "三明治法则""三句话公式""六词家教"
- "10/10/10决策""10-10-10决策"
- "随时表扬""定期反思""搭建阶梯""供给资源"
- "家庭教育原则""家庭教育规则""底线设定"
- "家长角色""父母角色定位"
- "各年龄段教育""婴儿期""幼儿期""青春期"教育

**典型用户问题示例**：
- "李希贵的家庭教育理念是什么？"
- "三明治法则怎么用？"
- "六词家教是什么？"
- "10/10/10决策工具怎么用？"
- "家庭教育应该遵循哪些原则？"
- "家长在孩子教育中应该扮演什么角色？"
- "随时表扬和定期反思怎么做？"
- "怎么给孩子搭建成长的阶梯？"

**与相邻skill的边界区分**：
- vs self-driven-parenting：li-xigui-parenting-guide侧重方法论体系和工具使用（如三明治法则、10/10/10决策），self-driven-parenting侧重心理机制和内驱力培养。当用户提到李希贵或具体工具时，li-xigui优先；当用户讨论焦虑、内在动机时，self-driven优先。两者可互补
- vs structured-thinking-decision：li-xigui中的10/10/10决策工具与structured-thinking-decision有重叠。当用户提到"10/10/10决策"或"李希贵的决策方法"时走li-xigui；当用户问通用的"怎么选"问题时走structured-thinking-decision
- vs brain-health-advisor：li-xigui涉及习惯培养和学习动力，brain-health-advisor涉及认知机制和学习方法。两者可互补

## structured-thinking-decision（结构化思维决策）

**来源**：基于《学习的逻辑》中结构化思维理论

**核心领域**：
- 家庭事务中的选择与判断
- 复杂问题的系统性拆解
- 多选项优劣分析
- 学习路径规划
- 升学规划
- 习惯培养方案设计
- 家庭资源配置决策

**触发关键词/场景**：
- "选哪个好""A和B怎么选"
- "怎么规划""XX规划"
- "不知道怎么决定"
- "信息太多太乱"
- "帮我分析一下"
- "优缺点对比"
- "要不要报/买/做"

**典型用户问题示例**：
- "孩子四年级了，奥数和编程该选哪个？"
- "小学六年怎么规划比较合理？"
- "课外班报太多还是太少，怎么判断？"
- "要不要让孩子从公立转国际学校？"
- "暑假怎么安排学习和活动的时间？"
- "家里老人的养老方案，几个选项怎么选？"

**与相邻skill的边界区分**：
- vs self-driven-parenting：structured-thinking-decision提供决策框架和分析方法，self-driven-parenting提供执行中的心理支持。通常决策在前、执行在后
- vs brain-health-advisor：决策中如涉及认知能力评估（"孩子适不适合学奥数"），可联合brain-health-advisor判断
- vs child-dev-learning：决策中如涉及发育能力评估（"孩子写字慢，该不该报书法班"），可联合child-dev-learning判断
- vs li-xigui-parenting-guide：li-xigui中的10/10/10决策工具与structured-thinking-decision有重叠。当用户提到"10/10/10决策"或"李希贵的决策方法"时走li-xigui；当用户问通用的"怎么选"问题时走structured-thinking-decision

## brain-health-advisor（脑健康家庭顾问）

**核心领域**：
- 儿童学习方法与学习效率
- 考试准备与应试策略
- 注意力训练
- 老年人认知健康与记忆衰退预防
- 阿尔茨海默病预防
- 成人自我提升与认知增强
- 脑保健产品/补剂评估（DHA、卵磷脂等）
- 脑科学书籍与专家观点解读

**触发关键词/场景**：
- "记忆力""记性不好""记不住"
- "注意力""专注力""容易分心"
- "学习方法""怎么学效率高"
- "备考""考试技巧"
- "DHA""卵磷脂""脑黄金""补脑"
- "大脑训练""认知提升"
- "老年痴呆预防""阿尔茨海默"
- "吃什么对脑子好"

**典型用户问题示例**：
- "孩子背了忘、忘了背，怎么提高记忆力？"
- "有什么方法能提升孩子的专注力？"
- "快考试了，怎么帮孩子高效复习？"
- "给老人买DHA有没有用？"
- "有没有什么推荐的大脑训练方法？"
- "卵磷脂和DHA该选哪个？"
- "听说某种补脑产品很好，是真的吗？"

**与相邻skill的边界区分**：
- vs child-dev-learning：brain-health-advisor从大脑认知机制角度解释学习问题，child-dev-learning从发育行为角度解释。如"背了忘"可能是记忆编码问题（brain-health）也可能是发育滞后问题（child-dev），可联合判断
- vs self-driven-parenting：brain-health-advisor提供"能力层面"的支持（怎么记得牢、怎么专注），self-driven-parenting提供"动机层面"的支持（为什么愿意学）。两者常需结合
- 核心价值提醒："脑营养是燃料，脑训练是引擎"——两者缺一不可；对带商业推广背景的专家推荐保持批判性评估

## child-dev-learning（儿童发育行为与学能发展）

**来源**：基于吕敏老师研究体系

**核心领域**：
- 发育行为亚健康状态评估与家庭干预
- 感觉统合失调识别与干预
- 视知觉障碍
- 读写障碍（ dyslexia ）
- 注意力缺陷多动障碍（ADHD）
- 高智商低成就现象
- 幼小衔接能力评估
- 儿童行为问题的深层原因分析

**触发关键词/场景**：
- "坐不住""动来动去"
- "漏题""看错题""粗心"
- "写字慢""写字丑""写不对"
- "背了忘""记不住"
- "阅读困难""不爱看书"
- "胆小""粘人"
- "经常摔倒""平衡不好"
- "成绩和智商不匹配"
- "幼小衔接"

**典型用户问题示例**：
- "孩子总是坐不住，是不是多动症？"
- "写作业经常漏题，看题也不仔细，怎么办？"
- "孩子很聪明但成绩上不去，怎么回事？"
- "写字特别慢，写几个字就要歇半天"
- "阅读时跳行漏字，是不是有问题？"
- "幼小衔接要准备什么能力？"
- "孩子经常磕磕碰碰，是不是感统失调？"

**与相邻skill的边界区分**：
- vs self-driven-parenting：child-dev-learning判断问题是否源于发育/能力缺陷，self-driven-parenting处理态度/动机问题。关键区分：如果换了方法、激励到位后仍然无法改善，考虑child-dev-learning排查发育问题
- vs brain-health-advisor：两者都涉及"学习困难"，child-dev-learning侧重发育行为评估（是否需要专业干预），brain-health-advisor侧重认知训练和改善策略。发育异常信号明显时，child-dev-learning优先
- **重要边界**：本skill提供评估和家庭干预建议，但涉及医学诊断（如ADHD确诊）必须建议用户就医，不得替代专业诊断

## family-mission-charter（家庭使命与宪章）

**来源**：基于史蒂芬·柯维《高效能家庭的7个习惯》

**核心领域**：
- 家庭使命宣言的创建与修订
- 家庭愿景描述（孩子维度/家庭维度/父母维度）
- 核心价值观萃取与共识
- 家庭行为宪章制定（四章结构：联结与信任、成长与探索、协作与共建、身心守护）
- 柯维7习惯的家庭映射
- 家庭使命愿景工作坊（2-3小时完整流程）
- 宪章践行评估与迭代机制
- 家庭会议/家庭仪式设计
- 情感账户管理

**触发关键词/场景**：
- "家庭使命""家庭愿景""家庭宪章""家训""家风"
- "柯维""7个习惯""高效能家庭"
- "家庭价值观""我们家要成为什么样的家庭"
- "家庭会议""家庭仪式""家庭夜晚"
- "情感账户"
- 家庭面临重大变化（搬家、入学、新成员）

**典型用户问题示例**：
- "我们家应该有个什么样的家训？"
- "怎么让全家人对教育目标达成一致？"
- "柯维的7个习惯在家庭里怎么用？"
- "怎么设计家庭会议？"
- "孩子大了，想重新梳理一下我们家的方向"
- "怎么让宪章不只是写在纸上，而是真正执行？"

**与相邻skill的边界区分**：
- vs li-xigui-parenting-guide：li-xigui提供教育方法论和原则（10条原则/7个角色/24种方法），family-mission-charter聚焦家庭集体愿景与共同承诺（使命/愿景/价值观/宪章）。当用户提到李希贵或具体教育方法时走li-xigui；当用户讨论"我们家要成为什么""家庭方向"时走family-mission-charter。两者可互补：li-xigui的方法可嵌入family-mission的宪章中
- vs self-driven-parenting：self-driven-parenting侧重个体心理机制（顾问型父母/非焦虑临在/控制感），family-mission-charter侧重家庭系统层面的方向共识。self-driven帮助父母个人稳定，family-mission帮助全家方向一致
- vs structured-thinking-decision：structured-thinking帮助做具体决策（选A还是选B），family-mission帮助定义决策的价值观基准（"我们家的原则是什么"）。宪章中的决策可调用structured-thinking方法

## child-self-reliance-skill-tree（孩子自立技能树）

**来源**：基于小学阶段（1-6年级）各年级心智发展特征

**核心领域**：
- 小学1-6年级心智发展特征（认知/时间概念/道德判断）
- 学习习惯、生活习惯、行为习惯的分层培养
- 主动学习激发（内驱力/学习空间/成果展示）
- 亲子决策授权五阶段阶梯（完全父母决策→父母给选项→双方协商→自主决定父母监控→完全放手）
- 各年级匹配的教育方法与心智发展指导

**触发关键词/场景**：
- "三年级该培养什么习惯"
- "怎么给孩子自主权"
- "各年级培养重点""一年级/二年级/三年级…"
- "学习习惯养成""生活习惯""行为习惯"
- "自主决策""放手""决策授权"
- "自立能力""自理能力"

**典型用户问题示例**：
- "三年级的孩子应该养成哪些学习习惯？"
- "我想给孩子更多自主权，但不知道放多少合适"
- "一年级和四年级的孩子，教育方式有什么不同？"
- "怎么培养孩子的自理能力？"
- "孩子自己的事情总是要我提醒，怎么让他自己负责？"
- "什么时候该完全放手让孩子自己决定？"

**与相邻skill的边界区分**：
- vs self-driven-parenting：self-driven-parenting侧重心理动机层面（控制感/胜任感/自主感），child-self-reliance-skill-tree侧重按年级匹配的行为习惯与授权节奏。self-driven回答"为什么不愿学"，child-self-reliance回答"这个年级该做什么、放多少权"
- vs structured-thinking-decision：structured-thinking-decision侧重复杂决策的方法论（多选项分析/长期规划），child-self-reliance-skill-tree侧重日常小事的渐进式放权（穿什么/作业顺序/兴趣班选择）。两者可结合：授权到高阶段后，孩子面临复杂决策时可调用structured-thinking方法
- vs child-dev-learning：child-dev-learning判断是否存在发育/能力问题（如感统失调/读写障碍），child-self-reliance-skill-tree假设发育正常，提供适龄的行为培养建议。如孩子"写字慢"，先经child-dev-learning排查是否为书写障碍，再经child-self-reliance给习惯培养建议

## child-goal-discovery（儿童目标感发现）

**来源**：基于威廉·戴蒙《目标感》理论

**核心领域**：
- 孩子目标状态诊断（疏离者/空想者/浅尝辄止者/目标明确者）
- 针对性引导策略（按四种状态匹配）
- "启示性时刻"创造方法（真实接触/能力匹配/社会连接/愉悦放大）
- 目标感支持系统搭建（定期对话/资源供给/容错空间/榜样示范）
- 父母实操对话指南
- 兴趣引导与人生方向探索

**触发关键词/场景**：
- "三分钟热度""对什么都提不起兴趣"
- "学习没动力""为什么要学习"
- "找不到人生方向""迷茫""空虚"
- "沉迷空想但从不行动"
- "兴趣培养""天赋发现""职业理想"
- "人生意义""未来规划"

**典型用户问题示例**：
- "孩子做什么都三分钟热度，怎么办？"
- "孩子问'为什么要学习'，我该怎么回答？"
- "孩子对任何事情都没兴趣，感觉很空虚"
- "孩子总说要当科学家，但从不为此努力"
- "怎么帮孩子找到真正感兴趣的领域？"
- "孩子快上初中了，还没想过以后要做什么"

**与相邻skill的边界区分**：
- vs self-driven-parenting：self-driven-parenting侧重日常学习动机（控制感/胜任感/自主感——"我想学"），child-goal-discovery侧重深层人生目标感（关心什么/为什么存在——"我为何而学"）。两者可互补：目标感是内驱力的 deeper layer
- vs structured-thinking-decision：structured-thinking-decision帮助做具体选择（选A还是选B），child-goal-discovery帮助孩子先"找到关心的真问题"（我连关心什么都不知道，怎么选）。通常先目标感发现，再结构化决策
- vs child-self-reliance-skill-tree：child-self-reliance按年级提供行为培养框架，child-goal-discovery帮助孩子找到驱动这些行为的内在意义。两者结合：有目标感的孩子，执行自立技能时更有动力
