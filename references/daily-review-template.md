# 日维度家庭管理复盘模板

> 基于每日家庭录音记录，输出四段复盘内容。
> 沉淀位置：飞书多维表格《LUMI手册-所有的输入-输出》—「智能家庭顾问诊断结论沉淀」表

---

## 输入

- 来源：得到大脑知识库「2.2-录音-家庭聊天」
- 范围：前一天全部录音与逐字稿

## 输出结构（四段式）

### 1. 根据"家庭教育综合质检评估框架"给到评估

基于五维框架，从录音中提取信号，给出当日维度评估：

| 维度 | 当日信号提取 | 评估 |
|------|------------|------|
| A. 父母稳不稳 | 录音中父母情绪状态、沟通方式 | 稳定/波动/失控 |
| B. 孩子自不自觉 | 孩子自主决策、自由时间、规则执行 | 自主/被动/抗拒 |
| C. 孩子学不学得了 | 作业场景、学习困难信号 | 顺畅/吃力/挣扎 |
| D. 家里养不养脑 | 饮食、运动、睡眠、屏幕时间 | 支持/一般/不足 |
| E. 家里决策乱不乱 | 家庭决策场景、夫妻沟通 | 清晰/模糊/冲突 |

### 2. 具体场景诊断

选取1-2个当日最具代表性的家庭互动场景，进行深度诊断：

- **场景描述**：发生了什么？谁在？说了什么？
- **理论视角**：用哪个skill的理论来解释？
- **诊断结论**：问题的本质是什么？
- **即时建议**：如果类似场景再发生，可以怎么做？

### 3. 需要改善的点

- 只列1-2个，不要多
- 每个点包含：问题简述 + 对应维度 + 优先级（今晚就做/本周内）

### 4. 需要被放大的亮点

- 只列1个，找到当天做得好的地方
- 包含：亮点描述 + 为什么这是亮点 + 如何保持

## 沉淀字段

| 字段 | 内容 |
|------|------|
| 报告标题 | 日复盘-YYYYMMDD |
| 类型 | 日复盘 |
| 周期 | 每日 |
| 报告日期 | YYYY-MM-DD |
| 总体评分 | 五维平均分（当日） |
| 最需放大亮点 | 第4段核心内容 |
| 最需改善点 | 第3段核心内容 |
| 录音来源 | 得到大脑2.2资料库 |
| 报告全文 | 四段完整内容 |
